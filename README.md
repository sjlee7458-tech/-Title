# 2023 한국 산업연관표 다층적 전후방 파급효과 분석 웹앱

## 1. 프로젝트 개요 및 데이터 출처
- **분석 주제**: 2023년 실측 투입산출표를 활용한 한국 핵심 산업(반도체·제조장비·전력인프라·소프트웨어)의 전후방 파급효과 및 분류 세분화 수준별 비교 분석
- **데이터 구성 (`data/io-2023.xlsx`)**:
  - 2023년 기준 실측 투입산출표(380개 기본부문, 생산자가격 기준)를 기반으로 다음 8개 시트를 구축했습니다.
  - **총거래표(경쟁수입형)**: `대분류_총거래표(6부문)`, `중분류_총거래표(15부문)`, `소분류_총거래표(24부문)`, `기본부문_총거래표(380부문)`
  - **국산거래표(비경쟁수입형)**: `대분류_국산거래표(6부문)`, `중분류_국산거래표(15부문)`, `소분류_국산거래표(24부문)`, `기본부문_국산거래표(380부문)`

## 2. 단위 안내
- **금액 단위(중간투입·중간수요·최종수요·부가가치·총산출·유발액)**: 백만원 (1조 원 = `1,000,000` 백만원)
- **투입계수($a_{ij}$), 생산유발계수, 부가가치유발계수**: 무차원 (최종수요 1백만원 변동당 유발되는 산출·부가가치 백만원 비율)
- **영향력계수(후방연쇄효과) 및 감응도계수(전방연쇄효과)**: 무차원 지수 (전 산업 평균 = `1.0000`)
- **상위 3개 부문 파급 집중도(CR3)**: 퍼센트(`%`)

## 3. 웹앱 사용 방법
1. **[기본 Excel 로딩 (data/io-2023.xlsx)]** 버튼을 눌러 2023년 실측 산업연관표를 불러옵니다.
2. **부문 분류 체계**(대분류·중분류·소분류·기본부문)와 **거래표 기준**(국산거래표 vs 총거래표)을 선택합니다.
3. 검색창에 부문코드(예: `3102`) 또는 산업명(예: `집적회로`, `반도체`, `전력`)을 검색하거나 추천 시나리오 버튼을 클릭한 뒤 **[산업연관분석 실행]**을 누릅니다.

## 4. 분석 모형 및 경제학적 해석
- **국산거래표 기반 유발모형**: $\Delta X^d = (I - A^d)^{-1} \Delta Y^d$, $\Delta VA = \hat{v}(I - A^d)^{-1} \Delta Y^d$
- **총거래표 기반 유발모형**: $\Delta X = (I - A)^{-1} \Delta Y$ (국산+수입 중간재를 모두 포함한 기술적 생산연관 구조)
- **집계 편의(Aggregation Bias) 비교**: 대분류(6부문)에서 소분류(24부문)·기본부문(380부문)으로 세분화할수록 평균화되었던 공급망 연결고리가 드러나며 상위 파급 부문의 집중도(CR3)가 변화하는 양상을 정량 비교할 수 있습니다.

## 5. 공개 저장소 보안 안내
- 본 저장소에는 집계된 국가 통계 기반 투입산출표와 분석 코드만 포함되어 있으며, 개인정보·비밀번호·API 키·비공개 자료는 일체 포함되지 않습니다.
